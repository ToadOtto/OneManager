# Инструкция для ИИ-агента: Миграция FTB Quests (1.20.1 Forge -> 1.21.1 NeoForge)

## Задача
Перенести квесты, главы (`chapters/`), награды и сохранённый прогресс игроков (`saves/.../ftbquests/`) из сборки Minecraft 1.20.1 (Forge) в сборку 1.21.1 (NeoForge) с адаптацией изменившихся идентификаторов, NBT и синтаксиса предметов.

---

## 1. Карта путей к файлам

| Компонент | Путь в 1.20.1 | Путь в 1.21.1 |
| :--- | :--- | :--- |
| **Квесты и главы** | `config/ftbquests/quests/` | `config/ftbquests/quests/` |
| **Глобальные файлы** | `chapters/`, `chapter_groups.snbt`, `file.snbt` | Те же пути внутри `quests/` |
| **Прогресс мира/игроков** | `<world>/ftbquests/` | `<world>/ftbquests/` |

---

## 2. Пошаговый протокол миграции

### Шаг 1. Резервное копирование
Перед запуском любых скриптов скопируй исходные папки в изолированный бекап:
- Создай папку `.migration_backup/` в корне.
- Скопируй туда `config/ftbquests/quests/` и `<world>/ftbquests/`.

### Шаг 2. Миграция синтаксиса предметов (1.20.1 -> 1.21.1)
В Minecraft 1.20.5+ Mojang полностью отказались от старого формата NBT в пользу **Data Components**. Любой предмет внутри SNBT-файлов квестов со старыми NBT-тегами вызовет сбой парсинга.

Выполни аудит и замену во всех файлах `.snbt` внутри `chapters/`:

1. **Формат NBT-данных предметов:**
   - **Старый (1.20.1):**
     `item: { id: "minecraft:enchanted_book", Count: 1b, tag: { StoredEnchantments: [{ id: "minecraft:sharpness", lvl: 5s }] } }`
   - **Новый (1.21.1):**
     `item: { id: "minecraft:enchanted_book", count: 1, components: { "minecraft:stored_enchantments": { levels: { "minecraft:sharpness": 5 } } } }`
   - **Заметка:** Если предмет без NBT (обычный ID и count), приведи ключ к нижнему регистру: `Count: 1b` $\rightarrow$ `count: 1` (FTB Quests 1.21 парсит строгий lowercase).

2. **Переименованные или удалённые идентификаторы:**
   - Проверь ID зелий: `tag: { Potion: "minecraft:swiftness" }` $\rightarrow$ `components: { "minecraft:potion_contents": { potion: "minecraft:swiftness" } }`.
   - Проверь кастомные предметы модов: убедись, что modid и registry name совпадают с версиями модов на 1.21.1.

### Шаг 3. Адаптация структуры глав и групп (SNBT)
1. Открой `config/ftbquests/quests/file.snbt`:
   - Убедись, что `version` соответствует текущей версии FTB Quests на 1.21.1 (не понижай вручную; оставь генерацию свежему моду либо обнови заголовок).
   - Проверь поле `default_quest_shape`.
2. Скопируй файлы глав из `quests/chapters/*.snbt` в целевую папку 1.21.1.
3. Проверь файл `chapter_groups.snbt` — убедись, что все `id` групп из глав зарегистрированы в этом файле.

### Шаг 4. Миграция данных игроков (`ftbquests/*.snbt` в мире)
Файлы прогресса игроков содержат hex-идентификаторы выполненных квестов (`q: 12345678L`) и наград:
1. Идентификаторы квестов (числовые лонги `...L`) **не меняются**, если файлы глав не пересоздавались с нуля.
2. Скопируй папки:
   - `<world>/ftbquests/players/`
   - `<world>/ftbquests/teams/`
3. Если в `players/*.snbt` есть выданные награды-предметы в старом формате NBT, вычисти устаревшие теги `tag: {...}` с помощью регулярного выражения или переведи их в `components: {...}`.
